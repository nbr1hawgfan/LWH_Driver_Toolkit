Tips

  • Drivers can't open message text while the truck is moving — it is read out loud instead, so write it the way you'd say it.
  • Use Must acknowledge for safety and policy notices. You'll see exactly who tapped Got It.
  • Back-and-forth conversations still belong in Samsara or a phone call.

Setup codes

Each driver signs in once in the Driver Toolkit: Messages → First time sign-in, their Driver ID, this setup code, then a PIN they choose. A code disappears from this list once it is used. Hand codes out in person or by text — treat them like a key.
